---
title: "Products API — manage the telecom service catalog"
description: "REST endpoints for managing telecom products (TV, Internet, IP Telephony) referenced by client contracts and used by the assignment engine to route claims."
---

Products represent the telecom services offered to clients (such as Internet, TV, or IP Telephony). Technical Employees are configured with the products they are qualified to support, and the assignment engine uses this to route claims correctly.

## Endpoints

| Method | Path | Role required |
|--------|------|---------------|
| GET | `/api/products` | Any authenticated |
| GET | `/api/products/{id}` | Any authenticated |
| POST | `/api/products` | Any authenticated |
| PUT | `/api/products/{id}` | Any authenticated |
| DELETE | `/api/products/{id}` | Any authenticated |

## Create a product

**`POST /api/products`**

<ParamField body="name" type="string" required>Product name (e.g., `Internet`, `TV`, `IP Telephony`).</ParamField>
<ParamField body="price" type="number" required>Monthly subscription price.</ParamField>
<ParamField body="description" type="string" required>Description of the service.</ParamField>

Returns HTTP 201 with the created product.

## Update a product

**`PUT /api/products/{id}`** — replaces all product fields. Returns HTTP 201 or 404.

## Delete a product

**`DELETE /api/products/{id}`** — returns HTTP 204 on success or 404 if not found.
